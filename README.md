# Identidade Oculta

Jogo de identidade oculta em React + Vite + TypeScript.

## Como rodar localmente

```bash
# 1. Entre na pasta do projeto
cd identidade-oculta

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev
```

Abra o navegador no endereço que aparecer (normalmente http://localhost:5173).

## Build para produção

```bash
npm run build
npm run preview
```
